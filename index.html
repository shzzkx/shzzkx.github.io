Speaker Box Project

MechanicalElectronicsSoftware

Seeeduino Nano, C++

A speaker box cabinet increasing the sound output of a 97.0 dB driver to 123.9 dB, which I designed in a team of 4. After researching cabinet design principles, we modelled a prototype in AutoCAD and physically assembled it with carboard. We conducted tests to determine what parameters maximised sound output, integrating these parameters into the control loop.

AutoCAD, SolidWorks

I measured a 3D-printed instrument by hand and recreated its orthogonal views in AutoCAD. I then modelled the same part in SolidWorks. This project taught me how to start with nothing but a physical part and create a fully dimensioned drawing and 3D model from it.
